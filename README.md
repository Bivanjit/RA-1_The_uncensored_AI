## 🎨 Design

The WormGPT interface is designed and developed by **Bivanjit** with an emphasis on:

- Minimal but distinctive UI
- Dark visual language
- Fast interaction
- Responsive layouts
- Clear chat hierarchy
- Custom WormGPT branding
- Future cloud/API compatibility

The interface is not intended to be a generic chatbot template.

---

## 💳 Credits

The frontend is designed to support a future server-side credit system.

The initial product concept uses:

**10 credits per user**

The frontend credit indicator is only a UI representation.

Actual credit enforcement will eventually happen on the backend/database rather than through client-side storage.
